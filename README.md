# Kêionny Unissys — Portfólio

Site pessoal com minha trajetória em tecnologia e dados: experiência, tecnologias, projetos e contato.

**Acesse:** https://keionnyunissys.github.io · [English version](https://keionnyunissys.github.io/?lang=en)

## Destaques

- Fundo interativo em `<canvas>` (rede de pontos que reage ao mouse e a cliques)
- Terminal interativo com comandos (`Ctrl + K` ou botão "Terminal")
- Versão em português e inglês, com detecção automática do idioma
- Repositórios do GitHub carregados automaticamente pela API pública
- Temas de cor, animações ao rolar e layout responsivo
- Respeita a preferência de "reduzir movimento" do sistema

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks e sem etapa de build.

## Estrutura

| Arquivo | Para que serve |
|---|---|
| `index.html` | Conteúdo do site (texto em português) |
| `style.css` | Visual, cores e responsividade |
| `config.js` | Links, WhatsApp e currículo, num só lugar |
| `i18n.js` | Traduções para o inglês |
| `script.js` | Fundo interativo, animações e repositórios do GitHub |
| `terminal.js` | Terminal interativo |
| `curriculo/` | Currículo em PDF |

## Rodar localmente

Basta abrir o `index.html` no navegador.
